Number Garden — Bella narration

Synthetic stock voice generated locally using Kokoro-82M v1.0 / af_bella.
Matches Operation Wild Explorer: fp32 CPU, speed 0.9, 24 kHz mono,
MP3 libmp3lame quality 2, uniform -2 dB gain. Leading/trailing silence is trimmed.
Fixed public game text only; no child names, handwriting, or saved progress
are sent to a speech service. The deployed game plays bundled MP3s and
does not run a speech model or use a paid generation service.

Model: https://huggingface.co/hexgrad/Kokoro-82M
ONNX: https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX
Code: https://github.com/hexgrad/kokoro/tree/main/kokoro.js
